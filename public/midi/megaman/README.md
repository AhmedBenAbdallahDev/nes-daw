# Bundled Mega Man MIDI Pack

Place your authorized MIDI files in this folder using exact filenames:

- `mega-man-2.mid`
- `mega-man-3.mid`
- `mega-man-4-title.mid`

The app loads these from:

- `/midi/megaman/mega-man-2.mid`
- `/midi/megaman/mega-man-3.mid`
- `/midi/megaman/mega-man-4-title.mid`

If any file is missing, the Test Song loader shows an error toast with the missing path.
